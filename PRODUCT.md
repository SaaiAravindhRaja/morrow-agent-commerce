# Product

## Register

brand

## Users

Hackathon judges first (StraitsX CEO/CTO, AWS Solutions Architect, Ava Labs), then a teammate running the demo. They have about sixty seconds and will not forgive a false claim about money or chain.

## Product Purpose

Morrow is a merchant API that sells AI agents a paid, time-limited commitment on scarce inventory. Two agents race. Only the winner is settled in 0.20 XSGD. The loser is never charged because settle is never called on them.

## Brand Personality

Plain, exact, slightly severe. Speaks in contracts and balances, not slogans.

## Anti-references

Generic SaaS cream dashboards. Neon "web3" landing pages. Diagrams that hide the live path behind AWS logos. Anything that implies a mainnet settlement or a running AWS account that does not exist.

## Design Principles

- Accuracy beats beauty. Label DEMO, LIVE, and PRODUCTION MAPPING on the thing itself.
- The whole story is visible without a click.
- One settlement, one winner, zero for the loser. That sentence is the product.
- System fonts only. The page must render offline.

## Accessibility & Inclusion

WCAG AA contrast in light and dark. Keyboard can select every diagram node. Reduced motion turns selection into an instant state change. Touch targets at least 44px on the page chrome.
