Live path

Authorize off-chain. Verify both. Funds do not move.

Both agents sign Permit2 authorizations. The merchant verifies both signatures. This is authorize-now, capture-later. Capture is settle.

Off-chain

Two Permit2 signatures

Each payload binds token, amount 200000, spender (exact proxy), nonce, deadline, and payTo. No transaction is broadcast.

Facilitator

Recovers the signer, checks balance, Permit2 allowance, unused nonce, deadline, network, and asset. Still no transfer.

Invariant

Zero XSGD has moved

A valid authorization is not a charge. The merchant now holds two unused permits and has not called settle.

05
Once per wallet

One-time Permit2 approve. After that, payments are signatures.

Mainnet XSGD has no EIP-3009. The payer calls XSGD.approve(Permit2, max) once, on-chain, and pays gas that one time. Every later commitment is an off-chain Permit2 signature. "Agent signs, no gas" is true from the second interaction onward. Rehearsed on the Anvil fork against real XSGD bytecode (56,650 gas).

If fork RPC or facilitator is down

DETERMINISTIC_DEMO

A deterministic simulation still runs the race and the winner/loser invariant. The UI labels the mode DETERMINISTIC_DEMO in plain words. A viewer cannot mistake it for a live settlement.

Production mapping

AWS Well-Architected callouts

  • Race: DynamoDB conditional write on one item. ConditionExpression is on this page. Failed condition emits RaceConflicts.
  • Idempotency: every mutate carries Idempotency-Key. Key maps to an outcome table (status, tx hash, timestamp, TTL 24 to 48 h). Duplicate key returns the stored outcome. REL04-BP04.
  • Compensating action: never settle the loser. On timeout, skip settle and release the lock only if lockedBy still matches. Expired locks clear with the same condition.
  • Observability: RaceConflicts, PaymentVerifyLatency, PaymentSettleLatency. Structured logs carry inventoryId, agentId, idempotencyKey, outcome.
Not in the live path

Drawn so a judge is not misled

EIP-3009

Mainnet XSGD typehash getters for transferWithAuthorization revert. Fuji sandbox XSGD is a different token. Live path is Permit2.

StraitsX card hold

Sandbox MCP exposes get_card_sandbox and view_card_sandbox only. It cannot hold. Loser-never-charged cannot be built on that MCP.

x402 upto

@x402/evm@2.22.0 hardcodes 0x4020A4f3b7b90ccA423B9fabCc0CE57C6C240002. That address has zero bytecode on Avalanche. Stock upto cannot settle here.
